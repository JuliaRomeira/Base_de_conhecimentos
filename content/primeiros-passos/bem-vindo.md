# Bem-vindo à Base de Conhecimento

Esta é a sua central de manuais, tutoriais e guias passo a passo. Aqui você encontrará tudo o que precisa para tirar o máximo de proveito do sistema.

## Como navegar

A documentação está organizada em **três grandes categorias**:

- **Primeiros Passos** — para quem está começando agora
- **Configurações** — personalize o sistema do seu jeito
- **FAQ** — respostas rápidas para dúvidas comuns

Use a **barra lateral** à esquerda para navegar entre artigos, ou a **busca** no topo para encontrar qualquer assunto rapidamente.

## Recursos disponíveis

> [!TIP] Dica de produtividade

4. Vídeos tutoriais embarcados
